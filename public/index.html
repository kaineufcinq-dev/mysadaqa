Recommandé

Option 1: En ligne (CB)

Le plus simple et rapide. Cliquez sur recharge.fr et achetez une recharge PCS avec votre carte bancaire. Mettez pays d'utilisation France même si vous êtes d'un autre pays. Instantané et sans déplacement.

🏪

Option 2 : Bureau de tabac (espèces)

Allez dans un bureau de tabac et demandez une recharge PCS. Payez en espèces. Pratique si vous préférez les espèces.

Étapes à suivre :

  1. Achetez une recharge PCS (20€, 50€, 100€, 150€, etc.)
  2. Vous recevrez un code
  3. Entrez ce code ci-dessous
  4. Cliquez sur "Envoyer"
